# Professional Portfolio - Jhonatan Zarzuri

This is a modern, high-performance professional portfolio built with React, TypeScript, and Three.js.

## 🚀 Technologies

- **Framework:** [React 18 + Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
- **3D Graphics:** [React Three Fiber](https://docs.pmnd.rs/react-three-fiber/) & [Drei](https://github.com/pmndrs/drei)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Internationalization:** [react-i18next](https://react.i18next.com/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🛠️ Features

- **Interactive 3D Hero Scene:** Smooth floating and distorting shapes.
- **Multi-language Support:** Easily switch between English and Spanish.
- **Responsive Design:** Optimized for mobile, tablet, and desktop.
- **Modern UI:** Glassmorphism effects, smooth transitions, and premium aesthetics.
- **Sectionized Content:** About, Skills, Experience, and Contact sections.

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd PORTAFOLIO
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 🌐 Deployment

The project is ready to be deployed on **Vercel** or **Netlify**.
Just connect your GitHub repository and it will automatically detect the Vite environment.
